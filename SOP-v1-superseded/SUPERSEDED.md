# Superseded — first draft, 14-section structure

This directory holds the **first draft** of the Parametrix MX60 SOP, written 2026-09-10 against
the source base as it stood before the TBC mobile mapping help was ingested (batches 2, 4, 6
and 7).

**It is superseded by `../SOP/`, which is itself superseded by `../deliverables/`** — the live
four-document set. Start there. This directory is retained because:

- Sections 1–11 (field collection) were drafted from the MX60 and TMI User Guides, which have
  not changed. Much of that text carries forward.
- Section 12 (office workflow) is the part the new evidence invalidated most heavily.
- Appendix D, the decision register, is the origin of the decision numbering used in the new
  document.

Do not issue, cite, or distribute anything in this directory.
