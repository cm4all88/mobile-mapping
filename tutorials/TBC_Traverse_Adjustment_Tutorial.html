Traverse Adjustment in Trimble Business Center

A step-by-step guide to importing conventional total-station data, defining a traverse, reviewing misclosures, and adjusting it in TBC with the compass, transit, or least-squares method.

01 · Overview

Before you start

A traverse adjustment spreads the measurement error found at closure across the traverse legs, so the final coordinates are consistent with fixed control. In TBC a single command, Adjust Traverse, both creates the traverse and adjusts it with the Compass (Bowditch) or Transit rule.[1] [4] TBC can also run a full least-squares network adjustment.[9]

Closed loop

Starts and ends on the same known point, with a known backsight azimuth. Gives a check on angles and distances, but cannot detect a scale or azimuth error in the starting control.

Closed connecting

Starts on one known pair of points and ends on a different known pair. Preferred, because it checks against independent control.

Open traverse

Does not close on known control. You can't compute a misclosure, so there is nothing to adjust. Avoid open traverses for control work.

You will need

  • Trimble Access job files (.job or JobXML .jxl) or other supported raw data from the total station.
  • Published coordinates for at least the start point and backsight, and for the closing point and foresight on a connecting traverse.
  • The project's datum, coordinate system, and units, plus the accuracy standard the job must meet (contract, agency such as WSDOT, or ALTA/NSPS).
  • A TBC installation appropriately licensed for the survey and adjustment commands used here. Trimble's help doesn't tie these commands to a specific license tier, so check with your CAD/software administrator.

02 · Project

Project setup

  1. Create a new projectChoose File › New Project† and pick the Parametrix survey template if one exists for your office. Otherwise use the default metric or US survey foot template.
  2. Set the coordinate systemGo to Project Settings › Coordinate System†. Select the zone, for example NAD83(2011) / Washington North (US ft), and the geoid model the project calls for.
  3. Check units and the grid/ground settingIn Project Settings › Units†, confirm distance (US survey ft or m), angle (DMS), and display precision. If the project is on ground coordinates, confirm the combined scale factor or project-to-ground settings before importing anything.
  4. Set computation optionsUnder Project Settings › Computations, confirm whether distances are reduced to grid or ellipsoid, and whether curvature and refraction corrections are applied.† The Computations settings page itself is documented in Trimble's help.[5]
  5. Save the projectSave it to the project folder using the standard naming convention before you import data.
Watch out

The wrong vertical units or grid/ground setting is the most common cause of a traverse that “closes badly” when the field work was actually fine. Check these settings before you import.

03 · Data

Import field data

  1. Open the Import paneHome › Import†.
  2. Browse to the data folderSelect the .job or .jxl files and click Import†. If TBC warns about a coordinate system mismatch, keep the project coordinate system unless you know the field job is correct.
  3. Check the importIn the Project Explorer, expand Station Setups† and Points. Each traverse station should have one setup (or more if you observed it in multiple sessions), with the correct backsight.
  4. Open the Plan ViewMake sure the shape looks right: no long spikes, no stations sitting at 0,0, and the traverse closes back on itself visually.
04 · Control

Set control points

The adjustment holds your control fixed and moves everything else. TBC needs to know which coordinates are “truth.”

  1. Enter or import control coordinatesUse the Create Point† command, or import a control CSV.
  2. Set the coordinate quality to ControlSelect the point in the Project Explorer, open its Properties pane, and set the coordinate quality to Control (horizontal, and vertical if you are holding elevation). The quality levels, from highest to lowest, are Control, Survey, Mapping, and Unknown.[6] [7] To change several points at once, Ctrl-select them in the Project Explorer and change the quality in Properties.[8]
  3. Match the point IDsControl IDs must match exactly the IDs used in the field (for example CP1, not CP-1). If they don't, rename the points or merge the duplicates.
  4. Verify the backsight azimuthCompute an inverse between the start point and the backsight (the Inverse† command) and compare it to the published azimuth or bearing.
Fixed vs. adjusted end stations

TBC holds a start or end station fixed when its position and orientation are known without the rest of the traverse, such as a setup over a known point or a resection. A start or end station positioned only from the traverse itself is adjusted. If both ends are that type, only the backsight and foresight are known, and Trimble calls this the weakest kind of traverse.[2]

05 · QA

Review raw observations

Fix blunders before you adjust. An adjustment spreads error around; it can't fix a bad observation.

06 · Traverse

Create the traverse

TBC has no separate “define” step. You create, edit, and adjust a traverse in the same Adjust Traverse command pane.[1] If the traverse was already adjusted in Trimble Access, it comes in with the job, and you can use the same command to edit the station list or settings and re-adjust it.[1]

  1. Check the traverse project settingsOpen Project Settings › Computations › Traverse.[1] Here you choose whether traverses are adjusted automatically or manually. In manual mode, TBC re-checks the traverse on every project compute but doesn't change the adjusted coordinates. It flags the traverse for re-adjustment when the change exceeds the horizontal and vertical tolerances you set.[5]
  2. Open Adjust TraverseSurvey › Optical › Adjust Traverse.[1]
  3. Name and create the traverseIn Traverse name, enter a name that includes the job and date, for example PX-2601_Loop1_2026-10-08, then click Create.[1]
  4. Select stations in orderAdd the station setups in the order they were occupied: the start station, the intermediate stations, then the end station. Each intermediate station must have a foresight to the next station.[2]
  5. Set the adjustment optionsChoose the angular, distance, and elevation methods described in the next section.
  6. Preview ResultsClick Preview Results to see the closure before anything is written to the project.[1] The Traverse Adjustment Report's Before Adjustment section shows the same misclosures, precision values, and traverse length.[3]
Stop and check

Compare the angular misclosure to the allowable value, usually K·√n seconds, where n is the number of angles and K comes from your specification.[11] [13] [14] If it's over the allowable value, or the precision ratio is below spec, go back to Review raw observations. Don't adjust a traverse that fails closure.

07 · Adjustment

Adjust & review

TBC applies the angular correction first and then distributes the linear misclosure.[4] [10]

  1. Choose the angular distributionTypically proportional to distance, or equal proportions when the legs are similar in length. These option names come from Trimble Access and FieldLink, which also offer None.‡[10] They are reference only. Use the matching choice in the TBC pane, whose wording may differ.
  2. Choose the linear (distance) adjustmentTBC's help documents two methods:[4]
    • Compass (Bowditch): adjusts latitudes and departures in proportion to the length of each leg.[4] This is the default choice when angles and distances are measured with similar precision, which is true of modern total stations.
    • Transit: Trimble's definition is that it adjusts latitudes and departures in equal proportions or in proportion to the lengths of the lines.[4] Textbooks reserve it for cases where angles are much more precise than distances.[11] [15]
  3. Choose the elevation adjustmentDistribute the vertical misclosure in proportion to distance or in equal proportions‡[10], or leave elevations unadjusted if you are carrying elevations from a separate level loop.
  4. ApplyWhen the preview is within spec, click Apply.[1] TBC writes adjusted coordinates to the traverse stations. Fixed start and end stations are not changed.[2]
  5. Open the Traverse Adjustment ReportClick the Traverse Adjustment Report icon on the Adjust Traverse pane toolbar, or open it from the Reports list in the Quick Access Toolbar.[3] Review these sections:
    • Before Adjustment: raw misclosures, precision, and length
    • After Angular Adjustment and After Distance Adjustment: what's left after each correction
    • End-Point Orientations and Fixed points: confirm TBC held the control you expected
    • Station Adjustments: the correction applied to each station, with a plan diagram[3]
Adjust before you build

Topo shots are computed from their station's coordinates, so adjust the traverse before you build surfaces or linework, and check a few sideshots afterward. Also note that merging a point in a manually adjusted traverse removes all of its traverse-adjusted coordinates and its report.[5]

09 · Alternative

Least-squares alternative

Use the Adjust Network command[9] instead of (not in addition to) a compass adjustment when the traverse has redundant measurements, such as cross-ties, reciprocal shots, multiple loops, or GNSS-tied control.

  1. Set the standard errorsSet the a priori errors in the Default Standard Errors section of Project Settings. For total station data, TBC starts with the values from the imported .job/.jxl file.[16] Enter values that match your instrument (for example 1″ or 2″ for angles, and 1 mm + 1.5 ppm for EDM), plus centering errors for the instrument and target.
  2. Select the fixed controlOn the Adjust Network pane tab that lists the control-quality coordinates†, check 2D, h (ellipsoid height), or e (elevation) for each control coordinate you want to hold.[9]
  3. Run a minimally constrained adjustment firstTrimble's adjustment workflow starts with a minimally constrained adjustment, before any additional control is held.[9] Fix only the minimum needed to position and orient the network. For a total-station-only network, that is usually one point and one azimuth.[12] This tests the observations on their own, so a bad control value can't hide in, or distort, the results.
  4. Evaluate the Reference Factor and Chi Square testThe Chi Square test checks whether your a priori error estimates agree with the adjustment. If it fails, look for blunders and systematic errors first.[9] [12] Then you can use the Weighting tab to improve the a priori error estimates.[9] Trimble's goal when adjusting the weighting scalars is to bring the Reference Factor toward 1.00.[9] Re-adjust and re-evaluate both values together. Don't just rescale errors until the test passes; a scalar far from 1 is telling you something about the data or the error model. Flag any residuals over about 3σ.[12]
  5. Add the additional control constraintsOnce the minimally constrained adjustment is clean, hold the rest of the trusted control and re-adjust. Large shifts at this stage point to a problem with the control, not the observations.
Don't mix methods

Pick one method per traverse. A network adjustment saves new coordinate records with quality Adjusted or Fixed in network adjustment and makes them each point's final value.[9]

Survey › Network › Clear Adjustment Results[9] does more than remove the adjusted coordinates. It also clears the adjustment transformation parameters, the coordinate fixes and adjustment flags, resets the weighting scalars to 1.00, removes the error ellipses, and recomputes the project. Running both methods on the same stations leaves two sets of results, so decide which one is the record.

10 · Deliverables

Reports & QA

  • Traverse Adjustment Report: misclosures, corrections, and adjusted coordinates.[3] Attach it to the survey QA file.
  • Network Adjustment Report: open it from the Adjust Network pane toolbar. It includes residuals, error ellipses, and statistical tests (least squares only).[9]
  • Point Derivation Report†: confirms which coordinate record each point is using.
  • Export the adjusted coordinates with Home › Export† using the office's standard PNEZD CSV format, and note the adjustment method and precision ratio in the survey narrative.
