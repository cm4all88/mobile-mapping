# Superseded — the single-document SOP

This directory holds the **second generation** of the MX60 documentation: one 68,000-word document
covering explanation, evidence, requirements and procedure together, built 2026-09-11.

**It is superseded by `../deliverables/`**, which splits the same material into four documents by
the kind of content each carries — Technical Manual, SOP, Field How To, Office How To. The split is
specified in `../deliverables/00-DELIVERABLE-ARCHITECTURE.md`.

It is retained because it is the source the four-document set was derived from, and because its
assembled form is occasionally easier to search than four separate documents.

> **Do not issue anything from this directory, and do not edit it.** Its facts are frozen at
> 2026-09-11 and have already diverged from the live set — the MX60 configuration was established
> as **Premium** on 2026-09-19, and later corrections have been made in `../deliverables/` only.
