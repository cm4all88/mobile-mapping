# 2. Related Documents

## 2.1 The document family

Four documents, used together.

| Document | Answers |
|---|---|
| **SOP** *(this document)* | What is required, and on whose authority |
| **Technical Manual** | Why the system behaves as it does, and what the evidence is |
| **Field How To** | How to run the MX60 in the vehicle |
| **Office How To** | How to process the data in Trimble Business Center |

**This SOP governs.** The other three support it: the Technical Manual explains the requirements,
and the two How To guides give the method for meeting them.

> **A How To cannot create a requirement.** If a How To states something that must be done and this
> SOP does not require it, one of the two is wrong — and this SOP is the one that decides.

## 2.2 Where each kind of question is answered

| Your question | Where |
|---|---|
| *Must I?* | This SOP |
| *Why does it work this way?* | Technical Manual |
| *What does this term mean?* | Technical Manual **§6** — the glossary for all four documents |
| *What do I press, in the vehicle?* | Field How To |
| *What do I click, in TBC?* | Office How To |
| *Where did this number come from?* | Technical Manual **Appendix B**, the reference dataset |

## 2.3 What this SOP does not contain

| | Why |
|---|---|
| **Numerical accuracy tolerances** | Trimble publishes no acceptance tolerance for the MX60, and none has been established by test on this system. A tolerance is set by the project (§17) |
| **Explanation** | Technical Manual |
| **Step-by-step method** | Field How To · Office How To |
| **Terminology** | Technical Manual **§6**. §3 below defines only the terms that carry procedural force here |

## 2.4 Which software this SOP describes

**Trimble Business Center 2026.10** and **Trimble Mobile Imaging Rev L**, running on a Trimble MX60.

Trimble changes both. Where a procedure here depends on a specific dialog, option or file name, the
Technical Manual cites the Trimble topic it came from, so a changed interface can be checked against
the source rather than guessed at.
